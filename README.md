🌐 DevLinks - Meu Primeiro Projeto Web

Projeto desenvolvido durante os estudos da Rocketseat como primeiro contato com desenvolvimento Front-end.

A aplicação consiste em uma página de links personalizada inspirada no conceito de "link na bio", permitindo centralizar redes sociais, portfólio e contatos em uma interface moderna e responsiva.

🚀 Tecnologias Utilizadas
  • HTML5
  • CSS3
  • JavaScript
  • Google Fonts
  • Ionicons
📋 Funcionalidades
  • Exibição de perfil personalizado
  • Lista de links para redes sociais e portfólio
  • Modo claro e modo escuro
  • Alteração dinâmica da foto de perfil conforme o tema selecionado
  • Interface responsiva para diferentes dispositivos
  • Ícones interativos utilizando Ionicons
💡 Conceitos Praticados

Durante o desenvolvimento deste projeto foram aplicados conceitos fundamentais de desenvolvimento web, tais como:

  • Estruturação semântica com HTML
  • Estilização utilizando CSS
  • Manipulação do DOM com JavaScript
  • Eventos de interação do usuário
  • Alternância de temas (Dark Mode / Light Mode)
  • Organização de arquivos Front-end
  • Responsividade

🛠 Como Executar
Clone este repositório
git clone https://github.com/adriano1silva/projeto-site
Acesse a pasta do projeto
cd projeto-site
Abra o arquivo index.html no navegador.

🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de consolidar os primeiros conhecimentos em desenvolvimento web, servindo como base para projetos mais avançados utilizando JavaScript, Node.js, APIs e bancos de dados.

📚 Aprendizados

Com este projeto foi possível compreender na prática:

  • Estrutura de páginas web
  • Manipulação de elementos HTML via JavaScript
  • Troca dinâmica de conteúdo na interface
  • Organização de código Front-end
  • Boas práticas iniciais de desenvolvimento
